# Maderegger CE Suite M3.2.0

Risikobeurteilung und Konformitätsbewertung für Maschinen auf Basis der Verordnung (EU) 2023/1230.

## Fachliche Grundlage
- Verordnung (EU) 2023/1230, insbesondere Anhang III
- EN ISO 12100 als Methodik für Risikobeurteilung und Risikominderung
- maschinenspezifische A-, B- und C-Normen

Die Anwendung ist eine strukturierte Arbeitshilfe. Die konkrete Anwendbarkeit, Normenausgabe und Konformitätsbewertung sind projektbezogen fachlich zu prüfen.
